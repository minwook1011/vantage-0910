# TRASS 순별 수출 트래커

화면: 데이터 허브 → **TRASS 순별 수출** 섹션 (`docs/trass-exports.js`)
데이터: `docs/data/trass_exports.json` · 입력: `python ingest_trass.py`

## 발표 주기

TRASS(한국무역통계진흥원)는 품목별 잠정 수출을 한 달에 세 번 낸다.

| 구간 코드 | 범위 | 나오는 시점 |
|---|---|---|
| `D10` | 1~10일 | 11일경 |
| `D20` | 1~20일 | 21일경 |
| `M` | 월 전체 | 익월 1일경 |

## 비교 원칙 — 같은 구간끼리만

1~20일 값은 **이전 달의 1~20일**(MoM), **작년 같은 달의 1~20일**(YoY)과 비교한다.
1~20일을 월 전체와 비교하면 영업일 수가 달라 증감률이 왜곡된다. 화면의 막대 차트도
선택한 구간 값만 월별로 이어 그리고, 가장 최근 막대를 빨간색으로 표시한다.

YoY·MoM·단가는 JSON에 저장하지 않고 화면이 계산한다. 비교 대상 관측값이 아직 없으면
원출처가 표기한 증감률(`reported`)을 대신 보여주고 `원출처` 표시를 붙인다.

## 값 넣기

```bash
# 한 칸 (금액=달러, 중량=순중량 kg)
python ingest_trass.py add --item dram --month 2026-09 --span D20 --usd 10643860000 --kg 143474

# 여러 칸 한 번에 — data_sources/trass_template.csv 를 복사해서 채운 뒤
python ingest_trass.py csv data_sources/trass_input.csv

# 확인
python ingest_trass.py list --month 2026-09
```

같은 (품목, 월, 구간)을 다시 넣으면 값이 바뀐 경우에만 갱신하고, 이전 값은 `history`에,
정정일은 `revised_at`에 남긴다. 잠정치가 확정치로 바뀌는 과정을 추적하기 위해서다.

## 초기값

2026-09 1~20일 5개 품목(메모리·DRAM·Flash·MCP·DRAM 모듈)은 증권사 텔레그램이 인용한
TRASS-BF 잠정치로 채웠다. 1차 출처가 아니므로 TRASS 화면에서 확인한 값으로 덮어쓰면
정정 이력이 남는다. 순중량은 원출처의 금액 ÷ 단가로 역산했다(단가 오차 ±1 $/kg).

## 주의 — 데이터 사용권

TRASS는 유료 회원 서비스다. 이 저장소와 GitHub Pages는 **공개**이며, 화면의 비밀번호
게이트는 브라우저에서만 동작하므로 JSON 파일은 누구나 받을 수 있다. TRASS 이용약관이
재배포를 제한하면 원자료를 공개 저장소에 계속 쌓는 것은 약관 위반이 될 수 있다.
약관을 확인하고, 필요하면 저장소를 비공개로 돌리거나 가공 지표(증감률)만 게시한다.

## 자동화에 대해

TRASS 로그인과 다운로드는 자동화하지 않았다. 계정 비밀번호를 스크립트나 CI에 넣지 않기
위해서다. 발표일(11일·21일·1일)에 TRASS에서 값을 확인해 `ingest_trass.py`로 넣는다.
